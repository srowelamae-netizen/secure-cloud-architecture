## Project Description
This activity demonstrates a proposed secure cloud architecture for a Student Management Application. The application allows users to view student information such as name, student number, course, year level, and email through a simple web interface, while the underlying design follows secure cloud networking and security practices.

## Architecture
Users → CDN → Load Balancer → Application Servers → Private Database

## Security Controls
- IAM
- MFA
- Firewall / Security Groups
- Private Subnets
- Encryption
- Logging
- Monitoring
- Backups
